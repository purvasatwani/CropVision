About CropVision

The problem

Plant diseases can reduce yield and quality, and early signs often show up on leaves. Many farmers have limited access to plant-pathology experts, so problems may be recognised late.

Motivation

CropVision explores whether a phone- or laptop-class device can give a fast first opinion from a leaf photo, helping a farmer decide whether to seek expert advice sooner.

Lightweight deep learning

The classifier uses transfer learning on MobileNetV3-Small, a network designed for mobile hardware. Pretrained ImageNet features are fine-tuned on labelled leaf images (PlantVillage), then converted to TensorFlow Lite with optional post-training quantisation to reduce size and latency.

Edge-AI architecture

Image capture, preprocessing, inference and storage all run on the same device: browser UI, Flask server, TFLite interpreter, SQLite history. Nothing is sent to a cloud service, so it can run on a Raspberry Pi or Jetson-class board once dependencies and model files are installed. Physical-device performance has to be measured on that hardware; see the README.

Research gap

Many published plant-disease models are evaluated only on controlled, lab-style images and are often presented as cloud services. This project focuses on a complete, offline-capable pipeline and on measuring size, latency and accuracy of the original versus optimised models.

System workflow

Photo → validation → centre-crop and resize to 224×224 → MobileNetV3-Small / TFLite → class probabilities → reference text → saved to scan history.

Limitations

  • The model only knows the crops and diseases in its training data, and will still pick one of them for a non-leaf or unfamiliar image.
  • PlantVillage images are taken against plain backgrounds; accuracy in real fields is usually lower than on the held-out test split.
  • Near-duplicate photos of the same leaf in the dataset can make test scores optimistic.
  • Several conditions look alike and can be confused; symptoms can also come from nutrient or water stress.
  • The care notes are general and not treatment prescriptions. Consult an expert.

Dataset & sources

Training data: PlantVillage leaf images. Check the licence of the copy you download (the TensorFlow Datasets catalogue lists it as CC0 1.0).
